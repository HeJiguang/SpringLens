# GitHub Assets

This folder contains repository-owned assets for GitHub presentation.

## Social preview

- Source: `social-preview.svg`
- Intended export size: `1280 x 640`
- Safe usage: export to PNG before uploading to the GitHub repository social preview setting

## Visual direction

- product-first, not architecture-heavy
- emphasize the runtime safety loop
- make Codex, Cursor, and CloudCode legible without turning the graphic into a logo wall

## Recommended upload order

1. Export `social-preview.svg` to PNG.
2. Upload the PNG in repository settings as the social preview image.
3. Record the GIF from `docs/demo/runtime-safety-flow.md`.
4. Add the GIF near the top of the README or pin it in the release/discussion post.
