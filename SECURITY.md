# Security Policy

## Supported versions

Spring Lens is still pre-`1.0`. Security fixes are applied to the latest maintained line first.

| Version | Supported |
| --- | --- |
| latest `0.x` | Yes |
| older snapshots | No guarantee |

## Reporting a vulnerability

Please do not open public issues for security problems.

Preferred path:

1. Use GitHub private vulnerability reporting if it is enabled.
2. If it is not enabled yet, contact the maintainers privately before disclosure.

Include:

- affected module
- affected version or commit
- impact
- reproduction steps
- any workaround you know
