# Code of Conduct

## Our standard

We want Spring Lens to be a project where people can discuss difficult technical tradeoffs without hostility, harassment, or personal attacks.

Examples of good behavior:

- technical feedback with evidence
- respectful disagreement
- welcoming questions from new contributors
- clear discussion of risks and tradeoffs

Examples of unacceptable behavior:

- insults or demeaning language
- personal attacks
- harassment
- deliberately disruptive issue, PR, or discussion behavior

## Scope

This applies to:

- issues
- pull requests
- discussions
- other project-managed collaboration spaces

## Enforcement

Maintainers may remove, edit, or reject contributions and interactions that violate this code of conduct.

## Reporting

If you experience unacceptable behavior, contact the maintainers privately when possible instead of escalating publicly.
