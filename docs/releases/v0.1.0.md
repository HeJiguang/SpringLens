# Spring Lens v0.1.0

Spring Lens v0.1.0 is the first release that feels like a usable product, not just an architecture sketch.

## What Spring Lens can help Codex, Cursor, and CloudCode do

Spring Lens gives coding agents a runtime control surface for Spring Boot.

That means an agent can:

- inspect a real execution instead of inferring behavior from source alone
- ask for slow SQL, exception context, and execution graph context through runtime tools
- inspect runtime safety risks that are easy to miss in code review
- convert findings into reviewable remediation drafts
- promote approved remediation into a governed control plane flow

## Why this release matters

This release establishes the core loop that makes Spring Lens understandable in one demo:

- application-side runtime truth
- server-side MCP and governance surface
- agent-facing runtime safety inspection and remediation drafting

## Recommended demo for this release

If you want to understand Spring Lens quickly, demo this chain:

```text
inspect_runtime_safety -> draft_runtime_safety_remediation -> promote_runtime_safety_remediation
```

That is the clearest expression of what Spring Lens adds on top of ordinary framework introspection.

## Who should try it

- engineers building coding-agent workflows around Spring Boot
- teams that want runtime-aware patch suggestions
- maintainers exploring a control-plane approach to governed instrumentation
