# Spring Lens v0.1.0

Spring Lens v0.1.0 is the first release that feels ready to try in a real coding-agent workflow.

## What this release makes possible

Spring Lens gives coding agents a runtime control surface for Spring Boot applications.

With this release, an agent can:

- inspect a real execution instead of inferring behavior from source alone
- retrieve slow SQL and exception context through task-oriented runtime tools
- inspect runtime safety risks that are easy to miss in ordinary code review
- turn findings into reviewable remediation drafts
- promote approved remediation into a governed control-plane flow

## Why it matters

This release establishes the shortest path from runtime evidence to reviewable action:

- application-side runtime truth
- server-side tool routing and governance
- runtime safety inspection and remediation drafting

## Best demo for v0.1.0

If you want to understand Spring Lens quickly, demo this chain:

```text
inspect_runtime_safety -> draft_runtime_safety_remediation -> promote_runtime_safety_remediation
```

That flow is the clearest expression of what Spring Lens adds on top of ordinary framework introspection.

## Who should try it

- engineers building coding-agent workflows around Spring Boot
- teams that want runtime-aware patch suggestions
- maintainers exploring a governed control-plane approach to instrumentation and remediation
